# 1CKK v2.6 replicate matrix 结果分析

跑法：5 configs × 3 seeds 的最小 replicate 矩阵（`CWLD_aq0_ca_w1/w1.5/w2`、`CWLD_default_aq0p5`、`PME_Baseline`，
每个配置 seed=0/1/2）。日志见 `L-IPS.o9826`，全程无 traceback/报错，5×3=15 条轨迹全部顺利跑完。

数据来源：
- 逐 seed 明细：`1ckk_v26_replicate_matrix_per_seed_metrics.csv`
- 按配置聚合 mean/std：`1ckk_v26_replicate_matrix_summary.csv`

这是对 `v2.6_results_analysis.md` 第 3+4 节提出的问题（单条轨迹噪声跟消融效应同量级）的直接回应：
给关键配置补上 3 个随机种子，用 mean ± std 重新判断效应是否显著。

## 显著性判据

脚本日志末尾自带的判据：若某配置的 mean 差异 ≲ 1 个 std（或 ≲ 2·std/√n 的标准误），就不能说
`a_q2` / `ca_source_weight` 的效应显著。逐项对照：

- **密度、温度、RMSD**：各配置间差异都落在各自 std 以内 → 无显著差异，体系整体稳定性未被破坏（符合预期）。
- **Ca-water 峰高 g(r)**：w2/default（1.80~1.82）比 w1/PME（~1.56）高，且 w2 组自身 std 很小（0.059），
  这个差异看起来是显著的；但 default 组 std 很大（0.366），跨 seed 波动大，"接近 PME" 的结论仍不稳固。
- **驻留时间 τ**：三个 seed 间波动本身很大（std/mean 达 20~40%），w1.5 的 350ps 明显低于 w2 的 515ps，
  但方差太大，还需要更多 seed 才能确认这是真实趋势还是噪声（呼应 v2.5 分析里 `ca_source_weight_sweep`
  的非单调结果——现在看更像抽样噪声）。
- **Salt-bridge 峭峰**：default(3.71±0.89) 的 std 几乎覆盖了它和 PME(3.06±0.27) 的差值，不能说这个差异
  显著；但 w2 vs PME（3.62 vs 3.06，各自 std 仅 0.12/0.27）看起来是稳的。

## 结论与下一步

1. 3-seed replicate 已经能把"快平衡量"（温度/密度/RMSD）的噪声问题基本解决——这些量本来就不显著，
   之前的担心可以放下。
2. 但 Ca-water 相关的关键判据（峰高、驻留时间、salt bridge）里，**default(aq0.5) 配置的 std 依然偏大**，
   仍然是"charge_weighted_density 是否真的最接近 PME"这一结论的主要风险点，建议给 default 配置再加
   2-3 个 seed 把 std 压下去，而不是急着定型。
3. `ca_source_weight` 从 1→1.5→2 的趋势里，w1.5 的 τ 值异常低看起来仍是噪声主导，不建议据此判断
   w=1.5 是"最优"点。
